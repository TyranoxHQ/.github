# Support

Need help with a **Tyranox** app or have a question? Here is where to find answers and reach us.

## Where to Get Help

1. **Community Discussions & Questions**
   - For setup help, usage questions, and feature discussions around **Beside**, visit [Beside GitHub Discussions](https://github.com/TyranoxHQ/beside/discussions).

2. **Bug Reports & Feature Requests**
   - If something is not working as expected or you want to suggest an improvement, please open an issue on the [Beside Issue Tracker](https://github.com/TyranoxHQ/beside/issues/new/choose).
   - When reporting a problem, let us know which device you are using (**Windows 10/11** or **Android 8.0+**) and what happened.

3. **Downloads & Releases**
   - Always download the latest official release from [GitHub Releases](https://github.com/TyranoxHQ/beside/releases/latest), [Gumroad](https://thismalabs.gumroad.com/l/beside-pro), [itch.io](https://thisma-labs.itch.io/beside), or our [SourceForge Mirror](https://sourceforge.net/projects/beside-app/).

4. **Security Vulnerabilities**
   - Do not post security issues in public tickets. Please follow the instructions in [`SECURITY.md`](./SECURITY.md) to report vulnerabilities privately.
