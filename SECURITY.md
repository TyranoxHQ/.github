# Security Policy

Security and privacy are foundational to **Thisma Labs**. Because our tools operate directly between your devices over your local network, we take every potential vulnerability seriously.

## Supported Products

We actively maintain and provide security updates for the latest release of:

| Product | Supported Version | Download |
| :--- | :--- | :--- |
| **Beside** (Windows 10/11 & Android 8.0+) | Latest release | [GitHub Releases](https://github.com/thisma-labs/beside/releases/latest) |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues or public discussions.**

Instead, please report them privately using GitHub's Private Vulnerability Reporting:

- **Report privately on GitHub:** [Submit a Security Advisory for Beside](https://github.com/thisma-labs/beside/security/advisories/new)

### What to Include in Your Report

To help us investigate quickly, please include as much of the following as possible:

1. A clear description of the issue and its potential impact.
2. Affected platform(s) (`Windows 10/11`, `Android 8.0+`, or both).
3. Step-by-step instructions to reproduce the issue.
4. Any relevant logs, screenshots, or proof-of-concept details.

## What to Expect

- We will review your report promptly and confirm receipt through the GitHub Security Advisory thread.
- We will work with you to understand and validate the issue, and keep you updated as we prepare a fix.
- Once a fix is released, we are happy to credit you in the release notes or security advisory if you wish.
