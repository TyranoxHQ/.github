**データを自分のデバイス内に保つ、軽量で高速なソフトウェア。**

Thisma Labs は、PC とスマートフォンで毎日使えるローカルファースト（Local-first）なツールを開発しています。私たちのアプリは、アカウント登録、クラウド中継サーバー、バックグラウンドでの追跡（トラッキング）を一切必要とせず、お使いのデバイス同士を直接つなぎます。

### [Beside](https://github.com/thisma-labs/beside)

**ローカル Wi-Fi を通じて、Windows と Android 間でファイル・フォルダ・テキストを直接共有。**

自分宛てにメールを送ったり外部のクラウドにアップロードしたりすることなく、Windows PC と Android スマートフォンの間で写真、書類、フォルダ、テキストを素早くやり取りしたい方のために作られました。

- **ダイレクトなローカル転送:** お使いの Wi-Fi ネットワーク内で **Windows 10/11** PC と **Android 8.0+** スマートフォンの間を直接データが行き来します。
- **標準で守られるプライバシー:** **相互 TLS 1.3（mTLS）**暗号化とデバイス認証で通信を保護します。クラウドサーバー不要、アカウント作成不要、トラッキングもゼロです。
- **軽量かつ高速:** コンパクトなインストーラーと低いメモリ使用量で、システムの動作を妨げません。

**ダウンロード・入手方法:**
- **GitHub Releases (Windows & Android):** [最新版をダウンロード](https://github.com/thisma-labs/beside/releases/latest)
