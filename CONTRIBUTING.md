# Contributing to Tyranox

Thank you for using **Tyranox** tools and helping make them better! You do not need to be a programmer to contribute. Clear bug reports, feature ideas, and helpful answers in community discussions are some of the most valuable contributions we receive.

## Ways to Contribute

### 1. Ask Questions or Share Ideas
Have an idea or want to talk with other users? Start or join a conversation in [GitHub Discussions](https://github.com/TyranoxHQ/beside/discussions).

### 2. Report a Bug
If an app crashes, fails to connect, or behaves unexpectedly:
1. Visit the [Issue Tracker](https://github.com/TyranoxHQ/beside/issues/new/choose) and select **Bug Report**.
2. Tell us your device platform (**Windows 10/11** or **Android 8.0+**) and the steps that led to the problem.
3. Never include private personal files or sensitive data in public screenshots or logs.

### 3. Request a Feature
Want a new capability or workflow improvement?
1. Open the [Issue Tracker](https://github.com/TyranoxHQ/beside/issues/new/choose) and select **Feature Request**.
2. Describe the problem you are trying to solve and how the feature would help you.

### 4. Submit Pull Requests (For Documentation & Open Repositories)
When contributing changes to public repositories in the organization:
- Keep changes focused on a single topic or fix.
- Follow the existing style and formatting of the repository.
- Fill out the pull request template clearly so maintainers can review your changes quickly.

## Code of Conduct

All participation in Tyranox repositories and community spaces is governed by our [Code of Conduct](./CODE_OF_CONDUCT.md).
